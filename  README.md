# C Programming Journey

This repository contains my C programming exercises, experiments, assignments, and projects as I learn the language.

## Learning Resources

- **Primary:** *C Programming: A Modern Approach* — K. N. King
- **Secondary:** *The C Programming Language* — Brian W. Kernighan and Dennis M. Ritchie

## Repository Structure

- `01_basics/` — introductory C programs and language fundamentals
- `projects/` — larger programs built as my C knowledge develops

## Development Environment

- Linux
- GCC
- GDB
- Visual Studio Code
- Git and GitHub

## Goals

- Build a strong understanding of C fundamentals
- Learn memory, pointers, and low-level programming concepts
- Develop good debugging and problem-solving habits
- Apply C knowledge to Linux and systems programming
- Build increasingly complex C projects
