## Programming Projects

The `projects/` directory contains the Chapter 2 programming projects I completed.

### `display.c`

Uses `printf` statements and whitespace to display a simple pattern of asterisks.

### `sphere.c`

Calculates the volume of a sphere using:

`V = (4 / 3) × π × r³`

This project also demonstrated an important difference between integer and floating-point division in C.

### `tax.c`

Reads a monetary amount from the user and calculates the amount after adding 5% tax.

### `polynomial.c`

Evaluates a polynomial using a value of `x` entered by the user.

The project was later modified to evaluate the expression using Horner's Rule, reducing the number of multiplications required.

### `dollar.c`

Breaks a dollar amount into the smallest number of `$20`, `$10`, `$5`, and `$1` bills.

This project introduced a practical use of integer division and the remainder operator `%`.

### `loan.c`

Calculates the remaining balance of a loan after three monthly payments.

The program converts an annual percentage interest rate into a monthly decimal rate and calculates each month's interest using the balance remaining from the previous month.

## Compiling

Programs can be compiled using GCC.

For example:

```bash
gcc sphere.c -o sphere
```

and executed with:

```bash
./sphere
```

Before committing the programs, I also checked them using additional compiler warnings:

```bash
gcc -std=c99 -Wall -Wextra -pedantic sphere.c -o sphere
```

The options used here are:

- `-std=c99` — compile according to the C99 standard.
- `-Wall` — enable many useful compiler warnings.
- `-Wextra` — enable additional warnings.
- `-pedantic` — warn about code that does not strictly conform to the selected C standard.
- `-o sphere` — name the generated executable `sphere`.

## Key Lessons

One of the most important lessons from this chapter was that C distinguishes between integer and floating-point arithmetic.

For example:

```c
4 / 3
```

performs integer division and produces `1`, while:

```c
4.0f / 3.0f
```

performs floating-point division and produces approximately `1.333333`.

I also learned that source files and compiled executables are different things. The `.c` source files are kept in the repository, while executables generated by GCC can be deleted and recreated whenever needed.
